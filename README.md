# `dasdynamics_voice`

ROS 2-пакет для распознавания голосовых команд пользователя и преобразования их в команды управления роботом.

## Описание

Пакет содержит две основные ROS 2-ноды:

- `voice_recognition_node` — получает аудиопоток со стандартного микрофона робота и преобразует речь в текст с помощью библиотеки Vosk.
- `user_command_detection_node` — анализирует распознанный текст, сопоставляет его с доступным списком команд и отправляет соответствующую команду роботу.

Распознавание речи выполняется локально, поэтому после установки библиотеки и голосовой модели подключение к интернету для работы ноды не требуется. [alphacephei](https://alphacephei.com/vosk/install)

## Ноды пакета

### `voice_recognition_node`

Нода получает аудиопоток с микрофона и публикует распознанный текст в топик:

```text
/recognized_text
```

Для распознавания используется библиотека [Vosk](https://alphacephei.com/vosk/), поддерживающая автономную обработку речи. Для работы ноды необходимо скачать и распаковать голосовую модель с официального сайта:

[Каталог голосовых моделей Vosk](https://alphacephei.com/vosk/models)

После загрузки модель необходимо указать в параметрах ноды или в файле запуска — в зависимости от реализации пакета.

### `user_command_detection_node`

Нода подписывается на топик:

```text
/recognized_text
```

Полученный текст сравнивается со списком поддерживаемых команд. Если распознанная фраза соответствует одной из команд, нода публикует команду в топик, из которого робот получает управляющие сообщения.

Список доступных команд можно изменить в файле:

```text
dasdynamics_voice/user_command_detection_node.py
```

> **Примечание:** В текущей версии алгоритм сопоставления команд требует дальнейшей оптимизации. В планах — улучшение обработки фраз и добавление нового функционала.

## Требования и установка

Для работы пакета необходимы:

- ROS 2;
- Python 3;
- подключённый и доступный системе микрофон;
- библиотека Vosk;
- библиотека для получения аудиопотока;
- голосовая модель Vosk.

В данном проекте используется дистрибутив **ROS 2 Lyrical**.

### Установка системных зависимостей

Обновите список пакетов:

```bash
sudo apt update
```

Установите необходимые системные пакеты:

```bash
sudo apt install -y \
    python3-pip \
    python3-pyaudio \
    python3-sounddevice \
    portaudio19-dev \
    libasound2-dev \
    build-essential
```

Для работы `sounddevice` в Linux также могут потребоваться библиотеки PortAudio и ALSA. [github](https://github.com/bob-ros2/voskros/blob/main/README.md)

### Установка Vosk

Установите Python-библиотеку Vosk:

```bash
python3 -m pip install --break-system-packages vosk
```

Вместо установки в системное окружение рекомендуется использовать виртуальное окружение Python. Это снижает вероятность конфликтов с пакетами, установленными через системный менеджер:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install vosk sounddevice
```

Если ROS 2-нода запускается из этого окружения, перед запуском необходимо активировать виртуальное окружение.

### Установка голосовой модели

1. Перейдите на [страницу моделей Vosk](https://alphacephei.com/vosk/models).
2. Выберите модель нужного языка.
3. Скачайте и распакуйте архив.
4. Укажите путь к распакованной модели в конфигурации пакета или файле запуска.

Например:

```text
/home/user/models/vosk-model
```

Конкретный путь и параметр зависят от реализации `voice_recognition_node`.

## Зависимости

Пакет предназначен для работы совместно с другими компонентами системы управления роботом. Для полноценного тестирования могут потребоваться:

- пакет с описанием робота;
- пакет симуляции;
- нода или система, подписанная на топик управляющих команд;
- настроенный микрофон.

Например, для запуска в симуляции можно использовать пакет `dasdynamics_simulation`:

```bash
git clone https://github.com/dasdynamics/dasdynamics_simulation.git
```

## Быстрый запуск

После сборки рабочего пространства запустите пакет командой:

```bash
ros2 launch dasdynamics_voice voice.launch.py
```

Перед запуском убедитесь, что:

- пакет Vosk установлен;
- голосовая модель скачана и распакована;
- путь к модели указан в конфигурации;
- микрофон доступен системе;
- все необходимые ROS 2-пакеты собраны и подключены через `source`.

Пример подключения рабочего пространства:

```bash
source install/setup.bash
ros2 launch dasdynamics_voice voice.launch.py
```

## Настройка команд

Список команд, на которые реагирует робот, можно изменить в файле:

```text
dasdynamics_voice/user_command_detection_node.py
```

В текущей версии список команд находится непосредственно в исходном коде ноды.

## Структура репозитория

```text
launch/
    voice.launch.py                         — основной файл запуска пакета

dasdynamics_voice/
    user_command_detection_node.py          — нода определения команд
    voice_recognition_node.py               — нода распознавания речи

resource/
    dasdynamics_voice                     — индексный файл ROS 2-пакета
```

Если в репозитории присутствуют дополнительные конфигурационные файлы или каталог с моделями, их также стоит добавить в эту структуру.
